# Share Project

Use **Share Project** from the editor toolbar to invite another creator to access the story saved in your account.

## Before you start

- You must be **signed in**.
- The current project must already be **saved to your account in the cloud**.

If the project has not been saved yet, save it first and then reopen the share dialog.

## Create an invite

1. Open **Share Project**.
2. Enter the invitee's email address.
3. Choose an access level:
   - **Read only** — opens the story in the reader.
   - **Read + comment** — lets the invitee leave review comments and text suggestions.
4. Click **Create invite**.

Maria Writer generates a secure invite link. Copy that link and send it to the recipient.

## Pending invitations

The dialog also shows active invitations for the current project so you can see who is still pending.

## Current scope

This sharing flow is designed for **reading and review**. Invitees can suggest text changes, and owners can accept those suggestions from the reader. Live co-writing and chapter collaboration are planned for a later phase.
