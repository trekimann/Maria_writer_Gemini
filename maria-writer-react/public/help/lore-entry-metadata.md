# Lore Entry Metadata

Manage the metadata for the current lore entry.

## Fields

- **Lore Entry Title**: The title of this lore document. Updating it will also update the H1 heading in the entry's content.
- **Setting Date**: An optional in-world date associated with this lore entry (e.g. when a historical event occurred). Format: `dd/MM/yyyy HH:mm:ss`.
- **Related Events**: Select timeline events that are relevant to this lore entry.
- **Characters**: Select characters mentioned or involved in this lore entry.

## Tips

- Linking characters makes it easy to cross-reference world-building details from the character detail view.
- Adding a date allows lore entries to appear alongside chapters in timeline context.
