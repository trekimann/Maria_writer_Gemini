# Lore Editor

The **Lore Editor** works identically to the Manuscript Editor and gives you a full rich-text writing environment for world-building documents.

## View Modes

- **Write**: The default editing experience with formatting shortcuts and @mention support.
- **Source**: Edit raw Markdown directly.
- **Preview**: View the rendered document.

## Formatting Tools

The toolbar provides standard formatting options:
- **Headings**: H1, H2, H3 for titles and section breaks.
- **Text Styles**: **Bold**, *Italic*, and Underline.
- **Comments**: Add notes to specific passages.

## @Mentions

Type `@` followed by a character's name to link them to this lore entry. Tagged characters are highlighted and tracked automatically.

## Context Menu Features

Right-clicking opens a context menu with tools including **Create Event** and **Auto-tag Characters** — the same tools available in the Manuscript Editor.

## Tips

- Use H2 and H3 headings to organise long lore documents into sections.
- Open the Lore Entry Metadata panel (three-dot icon next to the entry in the sidebar) to link events and characters.
